# SRC-1201 Implementation Plan

> Execute inline in the current session, with test-first regression coverage. The production-only design has already been approved by the user.

**Goal:** Prevent public txpool traffic from creating blocks which cannot propagate or be batched.

**Architecture:** Track a transaction byte budget in the mining environment. Share the budget across forced, regular and bundle transactions; preserve historical reconstruction and block validation.

**Tech Stack:** Go, existing miner/Engine API tests, op-node gossip and op-batcher channel tests.

## Global Constraints

- Budget: `8*1024*1024 - 1_000_000` bytes.
- Only Optimism production that fills from the txpool is limited.
- `NoTxPool=true`, historical validation and fork configuration retain their semantics.
- Do not change dependency manifests or stage pre-existing untracked files.
